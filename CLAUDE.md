# CLAUDE.md — SubEye Landing

## Project overview
Astro 6 SSR landing page for SubEye (subscription monitoring SaaS) deployed on Vercel.
Two locales: **en** (default, `/`) and **ua** (Ukrainian, `/ua/`).
Uses Tailwind CSS 4, TypeScript strict mode, bun for package management.

## Architecture

### Pages (SSR, `prerender = false`)
- `src/pages/index.astro` — EN homepage
- `src/pages/ua/index.astro` — UA homepage
- `src/pages/terms-of-service.astro` / `src/pages/ua/terms-of-service.astro`

### Component hierarchy
```
MainLayout.astro (SEO, fonts, analytics)
└── Landing.astro (t = getLandingDict(lang))
    ├── Header, Footer
    └── sections/: Hero, Features, Pricing, FAQ, CTA
```

### i18n
- `src/i18n/types.ts` — `LandingDict` type (source of truth for translation shape)
- `src/i18n/en.ts` / `src/i18n/ua.ts` — translation dictionaries
- `src/i18n/index.ts` — `getLandingDict(lang)` getter + re-exports
- **Never** add fields to dictionaries without updating `LandingDict` type first.
- Feature lists are **not** in i18n — they come from the plans API (see below).

### Key libs
- `src/lib/plans.ts` — fetches `https://app.subeye.cc/api/billing/plans` with `X-Api-Key: $PLANS_API_KEY`. Falls back to hardcoded `FALLBACK` on error. 1-hour in-memory cache. Exports `fetchPlans()`, `PlansResponse`, `PlanData`, `PlanFeatureKey`.
- `src/lib/paddle-pricing.ts` — fetches Paddle API for Pro plan price. Per-request (uses `Astro.request` for country headers). 5-minute in-memory cache keyed by price/product IDs. **Do not cache per country/lang** — the full price object with all overrides is cached; resolution happens per request. Exports `getProPricingModel({ lang, request, fallbackPrice, fallbackPlanName })`.
- `src/lib/app-links.ts` — constants for `app.subeye.cc` URLs.

## Pricing component (`src/components/sections/Pricing.astro`)
- Feature lists come from `fetchPlans()`, **not** from i18n.
- Free plan: all `included: true` features.
- Plus plan: **delta only** — features `included: true` in Plus but NOT in Free.
- Limits (maxSubscriptions, maxCategories) and quotas (AI insights, comparisons) are displayed below the feature list, also from API.
- `FEATURE_LABELS` maps API feature keys → i18n strings (defined inline in component).
- `getFeatureLabels(plan, excludeKeys?)` handles optional exclusion.

## Currency / locale rules
- `lang === "ua"` → show UAH (UA country override → UAH currency override → country-based).
- `lang === "en"` → show USD only. If Paddle base `unit_price` is not USD and no USD override exists, fall back to `fallbackPrice` string (from i18n). **Never show UAH for the EN locale.**

## Environment variables
```
PADDLE_API_KEY=           # Paddle API key
PADDLE_PLUS_PRODUCT_ID=   # Paddle product ID for Plus plan
PLANS_API_KEY=            # API key for app.subeye.cc/api/billing/plans
```
Local dev: use `PLANS_API_KEY=dev-plans-key`.

## SEO / performance notes
- `MainLayout.astro` contains all meta tags: canonical, hreflang (en/uk/x-default), OG, Twitter Card, JSON-LD (WebSite + Organization + SoftwareApplication with both plan offers).
- Sitemap generated by `@astrojs/sitemap` at build time.
- Fonts: `@fontsource-variable/nunito` (local, bundled — no external CDN).
- No client-side JS beyond Vercel analytics + inline theme-persistence script.
- OG images: `/public/og-image-en.png` and `/public/og-image-ua.png`.

## Conventions
- Astro components use `---` frontmatter for all logic; HTML is purely presentational.
- Tailwind 4 with `@layer` in `src/styles/global.css`. OKLCh color tokens.
- Shared UI: `Button`, `Card`, `Pill`, `SectionHeader`, etc. in `src/components/shared/`.
- `Card` has `default`, `primary`, `glass` variants.
- `Button` has `default`, `secondary`, `ghost` variants.
- All new sections should accept `{ t: LandingDict }` (and `lang: Lang` when needed).
